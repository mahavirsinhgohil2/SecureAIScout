# SecureAI Scout Manual QA Checklist

Use a browser and the repository root. Mark each box after observing the expected result.

AI trust statement: A language model explains findings and proposes a corrected patch when the verifier rejects one; deterministic rules decide what is real, a sandbox verifier decides what is verified, and a human approves.
